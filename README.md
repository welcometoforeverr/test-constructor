# TestConstructor — конструктор тестов

## Назначение

TestConstructor — учебный проект сервиса для создания и дальнейшего управления тестами. На текущем этапе реализован простой консольный сценарий: преподаватель задаёт название теста, создаёт вопрос с четырьмя вариантами ответа, указывает правильный вариант и получает предпросмотр и статус готовности теста к публикации.

Тема проекта выбрана из перечня преподавателя: **№87 «Конструктор тестов»**.

## Целевая аудитория

Основные пользователи — преподаватели и другие авторы учебных материалов, которым необходимо создавать тесты для проверки знаний.

## Предметная область

Предметная область связана с созданием тестовых заданий. Преподаватель создаёт тест, добавляет вопросы и варианты ответов, указывает правильный вариант и в дальнейшем сможет публиковать тест для прохождения пользователями.

## Основные сущности

- **Преподаватель** — автор и владелец теста.
- **Тест** — набор вопросов по определённой теме.
- **Вопрос** — формулировка задания внутри теста.
- **Вариант** — один из возможных ответов на вопрос.

## Основные функции

На этапе ПР1 реализованы следующие функции:

1. `validate_test_title()` — проверяет корректность названия теста.
2. `validate_question()` — проверяет наличие текста вопроса и корректность обозначения правильного варианта.
3. `get_test_status()` — определяет, готов ли тест к публикации или уже опубликован.
4. `build_question_preview()` — формирует текстовый предпросмотр вопроса и вариантов ответа.

Таким образом, требование ПР1 о реализации не менее трёх функций выполнено.

## Использованные возможности Python

В начальной реализации используются:

- строковые, логические и целочисленные типы данных;
- операции со строками;
- явное преобразование типа `str` → `int` через `int()` для проходного балла;
- условные конструкции `if`;
- пользовательские функции;
- импорт стандартного модуля `datetime`;
- форматированные строки.

На ПР1 намеренно не используются классы, циклы и сложная работа с коллекциями — эти возможности будут добавляться на следующих этапах курса.

## Запуск проекта

Требуется Python 3.10 или новее.

```bash
python main.py
```

Пример результата:

```text
=== Конструктор тестов ===
Преподаватель: Иванов Иван Иванович
Название теста: Основы Python
Дата создания: 2026-09-15
Проходной балл: 70%
Статус: Тест готов к публикации

Вопрос: Какой тип данных используется для целых чисел в Python?
A. int
B. float
C. str
D. bool
Правильный вариант: A
```

## Проверка через pytest

В проект добавлены простые автоматизированные проверки функций.

```bash
python -m pytest -q
```

- подключить базу данных для хранения преподавателей, тестов, вопросов и вариантов;

- контейнеризировать приложение с помощью Docker;
