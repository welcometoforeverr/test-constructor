# Система учета кулинарных экспериментов

Учебный сквозной проект по дисциплине «Технологии разработки приложений на базе фреймворков».

## Состояние проекта после ПР3

Функциональная модель ПР2 преобразована в объектно-ориентированную. Основные сущности предметной области представлены классами, коллекции содержат объекты, а JSON-загрузка восстанавливает связи между ними.

## Основные классы

- `User` — пользователь: `id`, `name`, `email`; методы `from_data()`, `to_data()`, `__str__()`.
- `Recipe` — рецепт: `id`, `name`, `category`; `validate_name()`, `from_data()`, `to_data()`, `__str__()`.
- `ExperimentResult` — результат: оценка вкуса и текстовый статус; `from_score()`, `from_data()`, `to_data()`, `__str__()`.
- `Experiment` — кулинарный эксперимент; хранит объекты `User`, `Recipe` и `ExperimentResult`; методы `cancel()`, `from_data()`, `to_data()`, свойство `status`, `__str__()`.

## Взаимодействие объектов

Объект `Experiment` связывает конкретного пользователя, рецепт и результат. Поэтому код обращается напрямую к связанным объектам, например `experiment.user.name`, `experiment.recipe.name`, `experiment.result.taste_score`.

## Возможности

- просмотр, поиск, сортировка и фильтрация рецептов;
- добавление рецептов;
- создание и отмена экспериментов;
- расчет результата по оценке вкуса;
- статистика по активным экспериментам;
- загрузка и сохранение объектов в JSON;
- обработка ошибок;
- автоматические тесты.

## Структура проекта

- `main.py` — консольный интерфейс;
- `models/` — объектная модель предметной области;
- `recipes.py` — операции с коллекцией объектов Recipe;
- `experiments.py` — операции с коллекцией объектов Experiment;
- `storage.py` — преобразование JSON ↔ объекты;
- `utils.py` — безопасный ввод;
- `data/` — JSON-файлы;
- `tests/` — pytest-тесты;
- `requirements.txt` — pytest и flake8.

## Примененные возможности ООП

Используются классы и объекты, `__init__`, атрибуты, методы экземпляра, `__str__`, `@staticmethod`, `@classmethod`, `@property` и композиция объектов. Функции хранения и обработки коллекций оставлены обычными функциями, поскольку они не являются поведением одного конкретного объекта.
