# Система учета кулинарных экспериментов

Учебный сквозной проект по дисциплине «Технологии разработки приложений на базе фреймворков».

## Назначение

Приложение позволяет хранить рецепты, фиксировать изменения при готовке, сохранять параметры кулинарных экспериментов и оценивать их результат.

Основные сущности: **пользователь, рецепт, эксперимент, результат**.

## Возможности ПР2

- просмотр, поиск и сортировка рецептов;
- фильтрация рецептов по категории;
- добавление новых рецептов;
- добавление и отмена кулинарных экспериментов;
- автоматическое определение результата эксперимента по оценке вкуса;
- подсчет количества экспериментов и средней оценки;
- сохранение и загрузка данных из JSON;
- обработка ошибок ввода и ошибок файлов;
- консольное меню;
- автоматические тесты pytest.

## Структура проекта

- `main.py` — точка запуска и меню приложения;
- `recipes.py` — функции работы с рецептами;
- `experiments.py` — функции работы с экспериментами и результатами;
- `storage.py` — загрузка и сохранение JSON;
- `utils.py` — безопасный ввод данных;
- `data/recipes.json` — рецепты;
- `data/experiments.json` — эксперименты и их результаты;
- `tests/` — автоматизированные тесты;
- `requirements.txt` — инструменты разработки.

## Использованные возможности Python

В ПР2 применены списки и словари, циклы `for` и `while`, функции, генератор через `yield`, `lambda` для сортировки, пользовательские модули, аннотации типов, `try/except`, работа с JSON и контекстный менеджер `with`.
