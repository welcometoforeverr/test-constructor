# CulinaryExperiments — система учета кулинарных экспериментов

## Назначение

CulinaryExperiments — учебный проект для учета изменений, которые пользователь вносит в рецепты, и фиксации результата каждого кулинарного эксперимента. На текущем этапе реализован консольный сценарий: пользователь выбирает рецепт, описывает изменение, указывает параметры приготовления, ставит оценку вкуса и получает итоговый результат эксперимента.

Тема проекта: **«Система учета кулинарных экспериментов»**.

## Целевая аудитория

Основные пользователи — люди, которые готовят по рецептам и хотят сохранять результаты собственных изменений: температуру, время приготовления, замену ингредиентов и итоговую оценку.

## Предметная область

Предметная область связана с хранением рецептов и учетом попыток их изменения. Пользователь выбирает рецепт, проводит эксперимент, фиксирует измененные параметры и сохраняет полученный результат. В дальнейшем можно будет сравнивать несколько экспериментов для одного рецепта.

## Основные сущности

- **Пользователь** — автор кулинарных экспериментов.
- **Рецепт** — исходное блюдо и его описание.
- **Эксперимент** — конкретная попытка изменить рецепт или параметры приготовления.
- **Результат** — итог эксперимента: оценка вкуса и статус успешности.

## Основные функции

На этапе ПР1 реализованы следующие функции:

1. `validate_recipe_name()` — проверяет корректность названия рецепта.
2. `validate_experiment()` — проверяет температуру, длительность и оценку вкуса.
3. `get_experiment_result()` — определяет итог эксперимента.
4. `build_experiment_preview()` — формирует текстовый отчет об эксперименте.

Таким образом, требование ПР1 о реализации не менее трех функций выполнено.

## Использованные возможности Python

В начальной реализации используются:

- строковые, логические и целочисленные типы данных;
- операции сравнения;
- явное преобразование `str` → `int` через `int()`;
- условные конструкции `if`;
- пользовательские функции;
- импорт `date` из стандартного модуля `datetime`;
- форматированные строки.

На ПР1 намеренно не используются классы и сложные структуры данных — они будут добавляться на следующих этапах курса.

## Запуск проекта

Требуется Python 3.10 или новее.

```bash
python main.py
```

Пример результата:

```text
=== Система учета кулинарных экспериментов ===
Пользователь: Калугин Никита
Дата эксперимента: 2026-09-24

Рецепт: Шоколадный кекс
Изменение: Уменьшено количество сахара на 20%
Температура: 180 °C
Время приготовления: 35 мин
Оценка вкуса: 9/10
Результат: Эксперимент успешный
```

## Проверка через pytest

## План развития

На следующих этапах планируется:

- представить основные сущности проекта в виде классов;
- создать веб-приложение на Django;
- подключить базу данных для хранения пользователей, рецептов, экспериментов и результатов;
- реализовать CRUD-операции для рецептов и экспериментов;
- добавить регистрацию, аутентификацию и разграничение доступа;

- добавить поиск и фильтрацию рецептов;
- разработать REST API;
- контейнеризировать приложение с помощью Docker;
- настроить автоматические тесты и CI/CD.
