# Система учета кулинарных экспериментов

Сквозной проект по дисциплине «Технологии разработки приложений на базе фреймворков».

## ПР5 — Django, HTTP и основы веб-разработки

Поверх консольной версии и классов ПР3 добавлен веб-интерфейс на Django 5.2. Сохранены `main.py`, `models/`, `storage.py`, `data/` и предыдущие тесты. Данные загружаются из JSON, Django ORM пока не используется.

Приложения: `homepage` (главная), `web_recipes` (рецепты), `web_experiments` (эксперименты). Имена двух приложений отличаются от `recipes.py` и `experiments.py`, чтобы избежать конфликтов импорта.

Адреса:

- `/` — главная;
- `/recipes/` — список рецептов;
- `/recipes/1/` — карточка рецепта;
- `/experiments/` — список экспериментов;
- `/experiments/1/` — карточка эксперимента.

На ПР5 HTML формируется view-функциями через `HttpResponse`. Страницы используют Bootstrap 5.3; неизвестные идентификаторы возвращают HTTP 404.

## Запуск

```bash
python -m pip install -r requirements.txt
python manage.py check
python manage.py runserver
```

Затем открыть `http://127.0.0.1:8000/`.

## Проверка

```bash
python -m pytest -v
flake8 . --extend-exclude=venv,.venv
```
