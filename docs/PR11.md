# ПР11 — Формы в Django

Калугин Никита Александрович · ЭФБО-12-24.
Проект: «Система учета кулинарных экспериментов» (CulinaryLab).

Цель: реализовать формы создания, редактирования, фильтрации и загрузки фото.

ExperimentFilterForm использует GET, is_valid и cleaned_data; ошибки
отображаются без аварийного завершения. RecipeForm и ExperimentForm —
ModelForm с явным списком полей, Bootstrap-виджетами и серверной валидацией.
GET отображает форму, POST сохраняет валидные данные и перенаправляет на
карточку. Дата не в будущем, положительные температура и длительность,
оценка 1–10 и непустое описание. Изменение эксперимента и результата
выполняется в одной транзакции; instance используется при редактировании.
Отмена сохраняет is_cancelled, выполняется только POST с CSRF. Отменённый
опыт нельзя редактировать. Неизвестные ID обрабатываются как 404.
Загрузка изображения рецепта: ImageField, Pillow, request.FILES, multipart,
MEDIA_ROOT и MEDIA_URL; файл хранится отдельно от static.
В предметной области допустимы повторные кулинарные эксперименты.

Тесты tests/test_pr11.py проверяют создание, изменение, отмену, CSRF, ошибки
ввода, 404 и загрузку изображения. Фактические результаты — GitHub Actions.
Яндекс Практикум: спринт «Формы в Django», урок «Работа с формами»;
прохождение подтверждается отдельно в личном кабинете.
Скриншоты реального запуска необходимы для отчёта.
