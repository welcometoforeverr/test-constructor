# ПР10 — Административная панель Django и работа с данными через ORM

Калугин Никита Александрович · ЭФБО-12-24.
Проект: «Система учета кулинарных экспериментов» (CulinaryLab).

Цель: освоить административный интерфейс и углубить работу с ORM.

Реализованы ModelAdmin для Recipe, User, Experiment, ExperimentResult;
локализованные поля и модели, поиск, фильтры и сортировка. Inline показывает
эксперименты участников и рецептов; результат связан с экспериментом OneToOne.
Миграции добавляют slug, человекочитаемые названия, варианты TextChoices без
замены имеющихся текстовых значений. QuerySet предоставляет методы active,
cancelled, completed, for_date, with_details. В запросах применяются Q,
filter, exclude, order_by, агрегаты, select_related и пагинация.
Сайт сохраняет старые URL по ID и добавляет адрес по slug.
Debug Toolbar подключается только при явном включении локальной отладки.

Особенности предметной области: результат опыта — отдельная сущность,
завершённый опыт имеет результат и не отменён; повторные опыты разрешены,
ограничение занятости из Roomly неприменимо.

Проверка: tests/test_pr10.py проверяет Admin, inline, slug и связанные запросы;
существующие ORM-тесты проверяют фильтры, сортировку, пагинацию и статистику.
Результаты CI — вкладка Actions репозитория. SQL можно показать во вкладке
SQL Debug Toolbar при запуске с CULINARY_DEBUG_TOOLBAR=1.

Яндекс Практикум: раздел «Базы данных и Django ORM», уроки 4, 5, 6,
прохождение ПР10 подтверждается отдельно в личном кабинете.
