# Защита ПР5 и ПР6 — короткая шпаргалка

**Что сделали на ПР5?** Добавили Django 5.2 к сквозному проекту, создали приложения homepage, web_recipes, web_experiments, настроили маршруты и view-функции. Показали реальные объекты из JSON в браузере.

**Что сделали на ПР6?** Заменили HTML-строки в Python стандартными Django-шаблонами. Данные передаются через render(), страницы наследуют base.html, карточки и навигация вынесены в include, оформлены CSS и JS.

**HTTP:** браузер отправляет запрос, Django подбирает маршрут в urls.py, запускает view, та возвращает HTTP-ответ.

**GET / POST:** GET — чтение; POST — отправка данных/изменения.

**200 / 404:** успешный запрос / объект или маршрут не найден.

**manage.py:** служебная точка входа. `python manage.py runserver` запускает сайт, `python manage.py check` проверяет конфигурацию.

**settings.py:** настройки Django и приложения. **urls.py:** маршрутизация.

**View:** получает запрос и подготавливает данные. **Template:** формирует HTML.

**render(request, template, context):** возвращает HTTP-ответ на основе шаблона и данных.

**context:** словарь переменных, доступных в шаблоне.

**extends / block:** наследование общих частей страницы. **include:** подключение повторяющегося фрагмента.

**for / if / empty:** цикл, условие и ситуация пустого списка в шаблоне.

**app_name + name:** пространства имен и именованные маршруты. `{% url 'recipes:detail' recipe.id %}` создает ссылку без жестко прописанного URL.

**Фильтры:** length считает элементы; default подставляет значение; truncatechars ограничивает длину.

**static:** CSS, изображения и JavaScript подключаются через `{% load static %}` и `{% static %}`.

**Почему JSON, а не Django ORM?** По методичке ПР5–ПР6 сохраняют объектную модель и JSON; переход на базу данных будет позднее.

**Как создается запись?** На этих этапах веб-интерфейс предназначен для просмотра, создание новых записей доступно через консоль `main.py`.

**Почему Django-приложения названы web_recipes / web_experiments?** Чтобы не конфликтовать с существующими файлами `recipes.py` и `experiments.py`.

**Пять страниц:** главная `/`, рецепты `/recipes/`, рецепт `/recipes/1/`, эксперименты `/experiments/`, эксперимент `/experiments/1/`.
