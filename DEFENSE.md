# Шпаргалка к защите ПР3

## Главное про ООП

**Класс** — описание типа объектов: какие у них данные и поведение.  
**Объект** — конкретный экземпляр класса.  
**__init__** — инициализирует атрибуты объекта при создании.  
**self** — ссылка на текущий объект.  
**Метод** — функция внутри класса, работающая с объектом.  
**__str__** — задает текст, который выводится через `print(object)`.

**Инкапсуляция** — данные и связанное с ними поведение объединены в объекте.  
**Наследование** — создание нового класса на основе существующего при отношении «является». В нашем проекте искусственно не применяется, потому что предметного основания нет.  
**Полиморфизм** — одинаковый интерфейс у объектов разных классов; например, у всех наших сущностей можно вызвать `str(object)`.  
**Композиция** — один объект содержит ссылки на другие объекты. В проекте `Experiment` содержит `User`, `Recipe` и `ExperimentResult`.

## Декораторы

**@staticmethod** — метод класса без `self`; в `Recipe.validate_name()` проверяет название.  
**@classmethod** — получает `cls` и умеет создавать объект из данных; используется в `from_data()`.  
**@property** — позволяет обращаться к методу как к атрибуту; `experiment.status` возвращает текущий статус без круглых скобок.  
Обычный декоратор — функция, которая оборачивает другую функцию и изменяет/дополняет ее поведение.

## Наш проект

Сущности: **User, Recipe, Experiment, ExperimentResult**.

- `User` хранит пользователя.
- `Recipe` хранит рецепт и умеет валидировать название.
- `ExperimentResult` хранит оценку и итог эксперимента.
- `Experiment` связывает пользователя, рецепт и результат; умеет отменяться и выводить свой статус.

В ПР2 были списки словарей. В ПР3 коллекции содержат **объекты**. Функции поиска/сортировки коллекций остались обычными функциями, а поведение конкретного объекта перенесено в методы.

## JSON

При загрузке: JSON → словарь → `from_data()` → объект.  
При сохранении: объект → `to_data()` → словарь → JSON.

## Тесты

Тесты проверяют создание классов, `__str__`, `@staticmethod`, результат по оценке, композицию объектов, отмену эксперимента, операции с коллекциями и полный цикл JSON → объект → JSON.
