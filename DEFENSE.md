# Краткие ответы к защите ПР1

## По материалам Python

**1. Какие основные типы данных используются в Python?**  
`int`, `float`, `str`, `bool`.

**2. Чем отличаются int, float, str и bool?**  
`int` хранит целые числа, `float` — вещественные, `str` — текст, `bool` — логические значения `True` и `False`.

**3. Для чего используется преобразование типов?**  
Чтобы получить значение нужного типа, например `int("180")` преобразует строку в целое число.

**4. Какие операции можно выполнять со строками?**  
Объединение, получение длины, поиск, изменение регистра и другие строковые операции.

**5. Какие операторы сравнения используются в Python?**  
`==`, `!=`, `<`, `>`, `<=`, `>=`.

**6. Для чего используется конструкция if?**  
Для выполнения кода только при выполнении заданного условия.

**7. В чем различие между if, elif и else?**  
`if` проверяет первое условие, `elif` — дополнительные, `else` выполняется, если предыдущие условия ложны.

**8. Как записываются составные условия?**  
С помощью выражений, объединенных операторами `and`, `or`, `not`.

**9. Для чего используются and, or и not?**  
`and` требует истинности обоих условий, `or` — хотя бы одного, `not` инвертирует значение.

**10. Что такое модуль Python?**  
Файл или библиотека с кодом, который можно подключить к программе.

**11. Для чего используется import?**  
Для подключения модулей и использования их возможностей.

**12. Чем импорт модуля отличается от импорта отдельного объекта?**  
`import datetime` подключает модуль целиком, а `from datetime import date` — конкретный объект `date`.

## По рабочему окружению

**13. Для чего используется виртуальное окружение Python?**  
Для изоляции зависимостей конкретного проекта.

**14. Что такое IDE?**  
Среда разработки с редактором, запуском программы и отладчиком.

**15. Для чего используется Git?**  
Для контроля версий и хранения истории изменений.

**16. Что такое репозиторий?**  
Каталог проекта, в котором Git хранит файлы и историю изменений.

**17. Что такое commit?**  
Зафиксированное состояние изменений проекта с сообщением.

**18. Для чего нужен .gitignore?**  
Чтобы Git не отслеживал временные файлы, виртуальное окружение, кэш и служебные файлы IDE.

**19. Для чего нужен README.md?**  
Для описания проекта, его назначения, сущностей, функций, запуска и плана развития.

**20. Что такое отладка?**  
Процесс поиска и исправления ошибок с наблюдением за выполнением программы.

**21. Что такое breakpoint?**  
Точка остановки программы в отладчике.

**22. Для чего используется пошаговое выполнение?**  
Чтобы выполнять код строка за строкой и следить за изменением переменных.

## По проекту «Система учета кулинарных экспериментов»

**23. Какую задачу решает выбранное приложение?**  
Приложение позволяет пользователю фиксировать изменения рецепта, параметры приготовления и итог кулинарного эксперимента.

**24. Кто является предполагаемым пользователем?**  
Человек, который готовит по рецептам и хочет сохранять результаты своих изменений и попыток.

**25. Какие основные сущности выделены?**  
Пользователь, рецепт, эксперимент и результат.

**26. Какие функции планируется реализовать?**  
Создание и редактирование рецептов, фиксацию экспериментов, хранение результатов, историю изменений, поиск и сравнение экспериментов.

**27. Какой сценарий реализован на текущем этапе?**  
Пользователь проводит эксперимент с рецептом «Шоколадный кекс»: уменьшает сахар, задает температуру и время, оценивает вкус, после чего программа определяет итог эксперимента и выводит отчет.

**28. Какие конструкции Python использованы?**  
Переменные, `str`, `int`, `bool`, преобразование типов через `int()`, сравнения, `if`, функции, импорт `date` из `datetime` и форматированные строки.

**29. Какие части проекта будут добавлены после изучения ООП и Django?**  
Сущности станут классами и моделями Django, появятся база данных, URL, views, HTML-шаблоны, формы, пользователи, авторизация, API и тестирование.

**30. Почему эта предметная область подходит для веб-приложения?**  
Потому что есть несколько связанных сущностей, данные нужно хранить в БД, нужны CRUD-операции, пользователи, история экспериментов и возможность предоставить REST API.
